# Origins by Nullorigo — 3D Edition

3D-издание генеративной коллекции Origins (3333 работы). Каждая 3D-работа строится из тех же трейтов токена, что и 2D-оригинал. Это световая скульптура над той же координатной плоскостью: при виде сверху она совпадает с 2D-фигурой.

## Файлы

| Файл | Что это |
|---|---|
| `origins.js` | 2D-генератор, единственный источник истины. **Не изменён**, подключается как есть. |
| `origins3d.js` | 3D: трейты → геометрия для каждого из 15 семейств → сцена three.js (пол, сетка, оси, чертёж 2D на полу, размытое отражение, нити, кубики, bloom, ACES, виньетка, зерно). |
| `viewer.html` | Интерактивный просмотр: номер токена, ← / →, random, орбита, рамка, вид сверху. |
| `render.html` | Служебная страница для headless-рендера. |
| `render.mjs` | Рендер PNG / контактного листа / видео-петли, пакетный режим на все 3333. |
| `fonts/` | Jost (Google Fonts, OFL), локально: рендер не зависит от сети. |
| `previews/` | Контактный лист шага 1 и превью эталонных токенов. |
| `PROMPT.md`, `origins-2d-references.jpg` | Исходное ТЗ и 2D-эталоны. |

## Запуск

```bash
npm install                      # three@0.160.0 + playwright
npm run serve                    # → http://localhost:8173/viewer.html?n=1
```

## Рендер

```bash
node render.mjs --contact                         # 18 эталонных токенов: 2D | 3D | 3D сверху → out/contact-sheet.jpg
node render.mjs 1 2 3                             # отдельные токены → out/png/0001.png (2048²) + out/metadata/0001.json
node render.mjs --from 1 --to 3333 --workers 4    # вся коллекция: продолжает с места остановки, проверяет «пустые» кадры
node render.mjs --video 1                         # петля 6 с, орбита ±20°, 1080² → out/video/0001.mp4 + .webm
```

Опции: `--size 2048`, `--ss 2` (суперсэмплинг), `--out out`, `--force` (перерендерить готовое), `--gpu` (видеокарта вместо программного SwiftShader, намного быстрее), `--base ipfs://CID/`, `--anim-base ipfs://CID/`.

Пакетный режим:
- пропускает уже готовые PNG;
- отбрасывает кадры со средней яркостью ниже порога;
- пишет ошибки в `out/failures.log`;
- работает в несколько воркеров.

Метаданные — это `ORIGINS.metadata(n)` плюс `animation_url` и трейт `Edition: 3D`.

## Как устроена картинка

- **Пол.** Тёмная плоскость, точечная сетка и оси с делениями ±12 как на 2D-карточке (1 ед. = 1 шаг сетки). На полу едва заметен сам 2D-оригинал, отрисованный `ORIGINS.draw`, как чертёж. Ниже — мягкое размытое отражение скульптуры. Пол никогда не попадает в bloom, а лёгкая глубина резкости действует только на пол.
- **Скульптура.** Нити `LineSegments2` с `worldUnits: true`, поэтому толщина задана в мировых единицах и не пропадает на расстоянии. Точки на кривых — квадратные кубики, ориентированные по осям, как квадраты в 2D. Bloom действует только на скульптуру, а для плотных семейств он ослаблен.
- **Золотая точка.** Золотой куб с пунктиром до пола и по полу до обеих осей, подпись `(x, y)` с настоящим минусом.
- **Рамка.** Строки, шрифты и цвета рамки и подписи золотой точки берутся из самого `origins.js` (перехватом вызовов `fillText`), поэтому они совпадают с 2D буква в букву.
- **Камера.** Одна для всех токенов: 30° над горизонтом, fov 38°, вид три четверти. Трейт `rotation` применяется к фигуре так же, как в 2D.

## Семейства → 3D

| Семейство | 3D-форма |
|---|---|
| Rose | лепестки загибаются вверх к кончикам |
| Spiral | спираль поднимается винтом, каждая ветвь — отдельная нить |
| Orbits | кольца-орбиты с небольшим детерминированным наклоном, как в планетарии, и ножка в центре |
| Waves | каждая линия на своей высоте, между ними еле видимые полотна |
| Phyllotaxis | семена на пологом куполе |
| Lissajous | z = A·sin(c·t + φ), где c = \|a − b\| (кривая замкнута) |
| Spirograph | корона: внешние петли выше, плюс мягкая волна |
| Harmonograph | третий маятник с тем же затуханием; след опускается по мере затухания, получается воронка |
| Rings | зиккурат: внутренние кольца выше, полые кубики остаются полыми |
| Times Table | каждая хорда выгибается дугой вверх, получается купол из струн |
| Envelope | линейчатая поверхность (седло) из прямых; у «nested» два слоя |
| Hilbert | 3D-кривая Гильберта: 64 или 512 точек |
| Sierpinski | 3D-игра хаоса: тетраэдр, пирамида, призма с вершиной |
| Constellation | у каждой звезды своя высота, тонкие отвесы до пола |
| Ulam | горящие числа становятся тонкими колоннами |
| Origin | увеличенный золотой куб и тонкий вертикальный золотой луч |
